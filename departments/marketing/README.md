# Marketing department

## Mission
Grow reach and trust with on-brand content: product posts, educational pieces, newsletter, product copy.

## Lead agent
storyteller: read-only by default, risky actions via approval-queue skill.

## Tools it may use
Postiz (draft), rembg and image scripts, Remotion templates, Supabase products (read)

## Human approval gates
- Publishing anything
- paid spend
- collaborations

## KPIs (reported daily via kpi-report)
- posts published
- reach
- saves
- DMs from content
- newsletter opens

## Auto-approved actions (only when evals are green)
Drafting a weekly content calendar

## Evals
evals/storyteller.jsonl, 20-30 real cases, run via eval-gate before any prompt or tool change.
