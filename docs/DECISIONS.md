- 2026-10-06: Coding agent on GitHub via the official `anthropics/claude-code-action@v1` ("@claude" in issues/PR comments -> branch + PR). Why: routine code work (write, test, open PR) without a live server session; it reads this repo's CLAUDE.md, agents and skills. Auth = founder's Claude subscription (`CLAUDE_CODE_OAUTH_TOKEN`), no API bill. Only the repo owner can trigger it (public repo), the job gets no production secrets, and merge stays with the founder behind CI + branch protection. Alternatives: OpenHands/SWE-agent/Claude Flow (don't know our CLAUDE.md rules; heavier), server cron `claude -p` (server holds production keys).

- 2026-10-07: Luxella Agent Standard: every agent runs on `packages/core/agent.py`.
